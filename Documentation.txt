# Milestone 1 Documentation  
## Speech-to-Text System Implementation

---

# 1️⃣ Introduction

The objective of Milestone 1 is to design and implement a functional Speech-to-Text (STT) system capable of:

- Capturing audio (file + real-time)
- Transcribing speech using offline models
- Evaluating transcription accuracy using Word Error Rate (WER)
- Preparing data for future diarization and summarization modules

---

# 2️⃣ System Architecture

## Pipeline Overview

Microphone / AMI Audio  
→ Audio Preprocessing  
→ Resample to 16kHz Mono  
→ Threaded Audio Capture  
→ Queue Buffer  
→ Whisper STT Model  
→ Raw Transcript Output  
→ Text Normalization  
→ WER Evaluation using jiwer  
→ WER & CER Results  

---

# 3️⃣ Technical Components

## 3.1 Speech-to-Text Model

Model Used: Whisper Small  
Framework: openai-whisper  
Language: English  
Hardware: CPU  

Reason for selection:
Whisper provides robust performance for conversational and meeting-style speech compared to lightweight models.

---

## 3.2 Real-Time STT Engine

The real-time system uses:

- sounddevice for microphone capture
- Python threading for asynchronous processing
- Queue buffer for audio chunk management
- Whisper model for transcription

This ensures:
- Non-blocking audio capture
- Continuous transcription
- Stable output

---

## 3.3 Dataset Used

Dataset: AMI Meeting Corpus  

Characteristics:
- Multi-speaker conversations
- Real-world meeting noise
- Overlapping speech
- Natural conversational style

Audio preprocessing applied:
- Trimmed 30-second segment
- Converted to mono
- Resampled to 16kHz

---

# 4️⃣ Evaluation Methodology

## Metrics Used

- Word Error Rate (WER)
- Character Error Rate (CER)

WER Formula:

WER = (Substitutions + Deletions + Insertions) / Total Words in Reference

Evaluation Library:
- jiwer (Python)

Normalization steps:
- Convert to lowercase
- Remove punctuation
- Remove extra spaces
- Strip whitespace

# 6️⃣ Challenges Observed

- Conversational fillers ("um", "uh")
- Accent variations
- Multi-speaker interruptions
- Background noise
- Transcript formatting differences

These factors typically increase WER in real-world evaluation.
